# Code provenance

RiegoAzuay DSS v1.0.0 was promoted from the evaluated source state
`RiegoAzuay-DSS-v1.0.0-rc6`. The promotion introduced the author-approved MIT licence,
final version identifiers, public/reviewer notices, and release documentation. It did not
change the scientific engine or the reported computational results.

The daily FAO-56 balance, layered soil storage, irrigation scheduling, turn-feasibility,
evidence-readiness, weather and soil gateways, reporting modules, and scientific regression
tests retain the evaluated implementation. `FINAL_RELEASE_PROMOTION_METADATA.csv` and
`FINAL_RELEASE_PROMOTION_RECORD.md` identify the source archives and promotion boundary.

The closed 2304-scenario retrospective experiment was not rerun during this licence and
metadata promotion.
