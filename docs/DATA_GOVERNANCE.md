# Data governance

The Provincial Government of Azuay inventory is a restricted institutional source.
Surrogate application IDs do not convert the source database into a public dataset.

The public v1.0.0 package may contain:

- original software code and non-confidential configuration;
- five synthetic territorial demonstration records;
- aggregate selector counts;
- public-data acquisition routines and source receipts;
- crop and soil reference parameters;
- selected non-confidential analytical and reproducibility outputs.

The public package must not contain:

- the processed 159-system selector;
- record-level institutional names or exact institutional intake coordinates;
- detailed record-level territorial audits;
- the raw institutional workbook;
- confidential questionnaire fields;
- credentials, private access tokens, or author-workstation paths.

The controlled reviewer package may contain the processed selector and detailed territorial
audits solely for confidential peer review under a non-redistribution condition. Those
restricted materials are not covered by the MIT software licence.
