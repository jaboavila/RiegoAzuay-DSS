# RC4 Methods and data-governance consistency note

RC4 is a packaging and confidentiality correction. It does not change the scientific
engine, the twelve equations, the interface calculation, the retrospective experiment,
or any reported numerical result.

The correction aligns the generated packages with the manuscript boundary:

- the public package contains code, synthetic territorial fixtures, public/modelled
  environmental evidence, aggregate selector counts, tests, and non-confidential outputs;
- the public package does not contain the processed 159-system registry, detailed
  institutional audit rows, named ambiguity records, accepted author-runtime outputs that
  reproduce restricted selector mappings, or exact institutional coordinate fingerprints;
- the reviewer-controlled package may contain the processed selector and detailed audit
  only for confidential review and must not be redistributed;
- author-workstation library paths are not included in distributed packages;
- the author freeze evidence retains the complete local inventory for audit.

The software licence, immutable repository release, reviewer-access mechanism, and DOI
remain pending and are not asserted by RC4.
