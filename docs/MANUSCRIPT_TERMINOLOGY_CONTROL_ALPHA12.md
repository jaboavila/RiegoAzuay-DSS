# Controlled manuscript terminology update before submission

The accepted software demonstrates that the decision horizon is defined by the current turn and the next declared turn, not by a fixed seven-day week. Before final manuscript assembly, apply these controlled wording changes without modifying equations or analytical results:

- Table 1 E2: **Provisional turn-level plan** / **Plan provisional hasta el siguiente turno**.
- Table 1 E3: **Operational turn-level recommendation** / **Recomendación operativa hasta el siguiente turno**.
- Replace generic references to a “weekly plan” where they imply a fixed seven-day frequency with “turn-level plan” or “plan until the next turn”.
- Retain “weekly” only when a specific seven-day experimental interval is being described.

This correction aligns the manuscript with the configurable current-turn and next-turn dates implemented in the accepted prototype.
